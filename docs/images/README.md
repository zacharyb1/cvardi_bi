# Documentation Images

This directory contains images used in the project documentation.

## Directory Structure

- `screenshots/` - Application screenshots for README
- `architecture/` - System architecture diagrams
- `demos/` - GIF demonstrations of features

## Guidelines for Adding Images

### Screenshots
- Use high-resolution images (minimum 1280x720)
- Show the actual application interface
- Highlight key features
- Compress images to reduce file size

### GIFs
- Keep duration between 10-15 seconds
- Focus on a single feature or workflow
- Use tools like LICEcap or ScreenToGif
- Optimize file size (target < 5MB)

### Architecture Diagrams
- Use tools like Draw.io, Excalidraw, or Mermaid
- Keep diagrams simple and clear
- Use consistent styling
- Export as PNG or SVG

## Adding Images to README

Reference images using relative paths:
```markdown
![Screenshot](docs/images/screenshots/main-interface.png)
```

For GIFs:
```markdown
![Demo](docs/images/demos/face-recognition-demo.gif)
```
